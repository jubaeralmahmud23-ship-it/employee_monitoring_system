# Research records

Persistent, auditable records for the research collaboration (CS / AI / business information systems).

| Path | Purpose |
|---|---|
| `00_PROJECT_LOG.md` | Stage-by-stage log: completed work, evidence, uncertainties, decisions, next actions. Start here. |
| `01_literature/<area>.md` | One file per literature area: search log, inclusion/exclusion criteria, evidence table, synthesis, candidate gaps, datasets, limitations, citation audit. |
| `02_candidate_ideas.md` | Preliminary candidate ideas, comparison table, recommendations, and the plan to test novelty and feasibility further. |
| `03_challenge/<idea>__novelty.md` | Adversarial prior-art search per idea (search log, comparison table, verdict, search limits). |
| `03_challenge/<idea>__feasibility.md` | Data, compute, approval and claim-support assessment per idea. |

Conventions:

- Every claim about a paper records its access depth. In this environment access is search-snippet level only; no full text or DOI resolver was reachable (see Stage 0 in the log).
- Nothing here is described as a systematic review. No screening counts or flow diagrams are reported.
- No experiment is reported as run unless its code, inputs, logs and outputs are in this repository.
